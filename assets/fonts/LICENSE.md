# 字体许可

本目录包含站点使用的本地字体子集，均为 SIL Open Font License 1.1 授权的开源字体。
发布站点时只包含下列 woff2 文件，不请求任何外部字体 CDN。

## Noto Serif SC

- 文件：`zr-serif-sc.woff2`（由系统安装的 NotoSerifSC-VF.ttf 子集化，仅保留本站用字，约 315 字形）
- 来源：<https://fonts.google.com/noto/specimen/Noto+Serif+SC>
- 版权：Copyright 2017 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
  Copyright 2014-2021 Adobe (http://www.adobe.com/).
- 许可：SIL Open Font License 1.1 — <https://openfontlicense.org>

## Bodoni Moda

- 文件：`bodoni-500.woff2`、`bodoni-600.woff2`、`bodoni-500-italic.woff2`
- 来源：<https://github.com/indestructible-type/Bodoni>（经 @fontsource 分发）
- 版权：Copyright 2020 The Bodoni Moda Project Authors
- 许可：SIL Open Font License 1.1 — <https://openfontlicense.org>

## 说明

SIL OFL 允许字体随网站一同分发、子集化与嵌入，但保留字体名称与版权声明。
本目录中的 woff2 是子集化后的发布副本，字体名称与原字体保持一致。
