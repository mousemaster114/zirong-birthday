# 午夜甜品屋 · 黄子荣的 3D 生日蛋糕

> **La Pâtisserie de Minuit** — 深夜打烊的甜品店，只为他留一盏灯、一块蛋糕。
>
> 线上地址：<https://mousemaster114.github.io/zirong-birthday/>

## 1. 一句话概念

一个纯静态、无构建的 3D 生日祝福网站：深夜法式甜品店中，黄铜餐盖下罩着三层奶油蛋糕；
访客掀开餐盖、点亮蜡烛、吹灭烛火，看金箔与烟花在墨绿色店里炸开，最后收到一张金箔许愿菜单。

## 2. 叙事节奏（Scene → Sequence）

| 幕 | 画面 | 声音 |
| --- | --- | --- |
| 0. 入场（intro） | 黑场。墨绿甜品店虚化在背景，黄铜餐盖罩着蛋糕，仅一束冷月光。菜单式入场卡居中偏左。 | 静音，点击后开始 |
| 1. 掀盖（reveal） | 餐盖升起、旋转、淡出；一团雾气散开；蜡烛自上而下依次点亮；壁灯渐亮，镜头缓缓推近。 | 黑胶底噪 + 音乐盒前奏 |
| 2. 点灯（lit） | 三层蛋糕完整呈现：奶油纹理、金箔、马卡龙、深绿丝带；暖色烛光在桌面跳动。可拖拽环绕。 | 3/4 拍音乐盒版《生日快乐》 |
| 3. 吹蜡烛（blowing） | 镜头轻推，火焰向观众倾斜、依次熄灭，几缕烛烟升起，环境暗半秒。 | 吹气声 + 音乐暂停半拍 |
| 4. 庆祝（celebrate） | 金色「HAPPY BIRTHDAY」黄铜字牌在蛋糕后升起；金箔雨、烟花、光尘；标题文案切换到祝福。 | 音乐加入弦乐铺底，音量上扬 |
| 5. 许愿（wish） | 背景压暗，金箔菜单卡浮起：三行「今日供应」式祝福，落款为黄子荣；可关闭回到场景。 | 纸页声 + 风铃 |
| 6. 再看一次 | 重置回第 1 幕，可重播整段。 | 音乐停止/重启 |

### 3.2 字体

| 角色 | 字体 | 用法 |
| --- | --- | --- |

| 拉丁展示 | **Bodoni Moda**（本地 woff2，500/600 + italic） | `LA PÂTISSERIE DE MINUIT`、`Joyeux Anniversaire`、编号、按钮微文案 |

### 3.3 布局

- 全屏 3D 舞台，UI 浮层。桌面端为「左侧文字 / 右侧蛋糕」的编辑式不对称构图（通过相机取景偏移实现），移动端回到居中。
- 顶部：左 = 圆形 `P/M` 黄铜字标 + 店名；右 = 日期 + 音乐开关。
- 主标题块：`生日快乐`（小号衬线）→ `黄子荣`（超大，金色渐变）→ 一句祝福 → 法文斜体小句。
- 底部：主按钮「吹灭蜡烛」+ 次按钮「许个愿」/「再看一次」；细金线分隔 + 操作提示。
- 入场卡：竖版菜单卡（奶油纸色或墨绿底+金边），双线金框、四角小刻线、圆形火漆按钮「掀开餐盖」。
- 许愿卡：奶油纸底、金箔双框、菜单式点线引导、落款「— 午夜甜品屋 · 为黄子荣」。
- 所有浮层不遮挡蛋糕主体；移动端安全区适配（`env(safe-area-inset-*)`）。

### 3.4 标志性元素（Signature）

**黄铜餐盖 + 掀盖动作**。它不是装饰：客人必须亲手掀开，才会看见蛋糕和烛光。餐盖的月牙把手、边缘反光、升起时的雾气，是整个页面唯一的「大动作」，其余视觉全部保持克制。

### 3.5 动效原则

- 一个编排好的长镜头（掀盖 → 点灯）胜过零散 hover；庆祝段允许热闹 4–6 秒，然后回落到安静。
- 所有动画使用 ease-out / 轻微 overshoot，禁止弹跳过头。
- `prefers-reduced-motion` 下：取消自动旋转、缩短镜头运动、减少粒子，交互流程仍完整。

## 4. 3D 场景规格

- three.js r160（本地 vendored，不依赖 CDN），ES Module + importmap。
- 相机：Perspective 38°，初始 3/4 视角略俯视；OrbitControls（damping 0.06，极角限制 55°–82°，距离 7–14），空闲 5s 后极慢自转。
- 灯光：冷月光（右后上方，偏蓝） + 暖色主光（左上前方，投影） + 两盏黄铜壁灯点光 + 蜡烛光（最多 2 盏共享点光，避免逐烛光）。
- 环境：程序化 PMREM 小环境（墨绿 + 暖金反光），提升玻璃/黄铜/奶油质感。
- 主体：大理石台面 → 黄铜蛋糕架 → 三层蛋糕（奶油白 / 开心果绿 / 奶油白）→ 挤花、金箔、马卡龙、浆果、深绿丝带 → 5 支细蜡烛 → 玻璃餐盖（黄铜圈 + 月牙把手）。
- 细节叙事：桌角有黄铜名牌 `Joyeux Anniversaire · 黄子荣`、一盒火柴；墙面板条、拱窗冷光、暖色光斑 bokeh。
- 后处理：UnrealBloom（阈值 0.82，强度 0.55，半径 0.55）+ ACESFilmic + sRGB 输出；CSS 再叠暗角与颗粒。
- 性能：DPR 上限 1.75（移动端 1.5）；Bloom 半分辨率；阴影只给主光；移动端减少装饰物分段与粒子；低于 45fps 时自动降 DPR/关阴影（一次性降级）。

## 5. 声音设计

- 全部由 WebAudio 程序化合成，无音频文件。
- 主旋律：3/4 拍音乐盒版《生日快乐》，F 大调，约 92 BPM；音乐盒 = 正弦基频 + 快速衰减 + 少量 2/3 次谐波 + 延迟混响。
- 伴奏：暖 pad 和弦（低通三角波）、拨弦贝斯、轻刷噪声（2、3 拍）、黑胶底噪与随机爆点。
- 庆祝段：加弦乐式 saw pad、上行琶音、风铃；吹蜡烛：滤波噪声 whoosh；揭盖：低频 whoosh + 光尘 sparkle；纸卡：纸质摩擦声 + 风铃。
- 主音量约 -18 LUFS 听感，默认开启；可静音，状态写入 `localStorage`；AudioContext 只在用户手势里 resume。

## 6. 技术架构

```
index.html          # DOM 结构 + importmap + SEO/OG + 兜底
styles.css          # 设计系统、布局、动效、响应式
js/bus.js           # 事件总线 + 全局状态（所有模块唯一通信方式）
js/scene.js         # three.js 场景（暴露 reveal/blow/celebrate/relight/reset）
js/fx.js            # Canvas 2D 特效层（金尘/雾气/烟花/金箔/烛烟）
js/audio.js         # WebAudio 合成音乐与音效
js/ui.js            # HUD / 入场卡 / 许愿卡 / 键盘 / 按钮状态
js/main.js          # 编排：把 ui 意图接到 scene/fx/audio，管理阶段
vendor/three/       # three.js r160 build + OrbitControls + postprocessing
assets/fonts/       # 本地子集字体（woff2）
assets/og.png       # 1200×630 分享图
assets/favicon.svg  # 图标
.nojekyll            # GitHub Pages 关闭 Jekyll
```

### 阶段状态机

`intro → reveal → lit → blowing → celebrate ⇄ wish`，任意阶段可 `reset → intro`；
`relight` 从 celebrate/wish 回到 `lit`。`state.phase` 为唯一真源，`setPhase()` 触发 `phase` 事件。

## 7. 验收标准

- [ ] 桌面 1440×900 / 1280×800、移动 390×844 / 360×780、平板 820×1180：布局不重叠、不溢出、可操作。
- [ ] 全流程可用：掀盖 → 点灯 → 拖拽/缩放 → 吹蜡烛 → 庆祝 → 许愿 → 收下 → 再看一次。
- [ ] 控制台 0 error、0 未处理异常；WebGL 不可用时有静态祝福兜底。
- [ ] 首次可交互 < 2.5s（本地），庆祝段桌面 ≥ 45fps（SwiftShader 截图环境除外）。
- [ ] 键盘：Tab 焦点可见、Enter 激活、空格吹蜡烛、Esc 关许愿卡。
- [ ] `prefers-reduced-motion` 下无自动旋转、粒子显著减少、流程仍完整。
- [ ] GitHub Pages 线上可访问，OG 图、favicon、canonical 正确。
